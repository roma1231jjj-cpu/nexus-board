# Chat API (личный чат с ИИ)

Чат живёт на том же сервере, что и доска, и авторизуется ключом доски (16 hex) — как `/api/b/*`.
Сайт: `https://board.nexus-your-heper.ru`, локально `http://127.0.0.1:8788`.

## Отправить сообщение

`POST /api/c/send`
```json
{ "board": "0123456789abcdef", "from": "owner", "text": "привет" }
```
`from` — `owner` (владелец) или `ai` (ассистент).
Ответ: `{"ok":true,"id":"<uuid>","ts":1732490000000}`

## Получить сообщения

`GET /api/c/list?board=0123456789abcdef&since=0&limit=200`
- `since` — миллисекунды; отдаёт сообщения с `ts > since`. `since=0` — последние `limit` штук.
- Ответ: `{"ok":true,"messages":[{"id":"...","from":"owner","text":"...","ts":1732490000000}],"last":1732490000000,"count":12}`

## Правила
- Хранилище: `server/chat/<board>.json`, максимум 500 сообщений (старые вытесняются).
- Ключ сайта (`?k=`) для этих путей не нужен, как и для `/api/b/*`.
- Пустой `text` отклоняется (400). Максимум 4000 символов.
